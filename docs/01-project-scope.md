# Project scope

The Caesar Cipher Security Lab is a teaching application for classical substitution cryptography. It is designed to demonstrate encryption, decryption, brute-force search, letter-frequency analysis, input validation, and local audit history.

## In scope
- Explain a small finite key space with repeatable examples.
- Help learners compare expected and observed transformations.
- Demonstrate why classical ciphers are unsuitable for modern confidentiality.
- Exercise defensive software practices such as validation and tests.

## Out of scope
This project is not a production cryptographic library, password manager, or secure messaging tool. Do not use it to protect sensitive information.
