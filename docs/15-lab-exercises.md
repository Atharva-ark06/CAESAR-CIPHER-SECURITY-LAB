# Suggested lab exercises

1. Encrypt and decrypt a message using keys 0, 3, and 25.
2. Explain why keys k and k + 26 produce the same output.
3. Compare brute-force candidates for a short and a long sentence.
4. Calculate letter percentages by hand and compare with the tool.
5. Explain why frequency analysis can be unreliable for very short text.
6. Identify what information is persisted in the local audit database.
7. Propose a privacy-preserving audit event that avoids storing plaintext.
8. Write a regression test for a boundary case before changing code.
