# Contributing

1. Create a focused branch from `master`.
2. Make a small change with a descriptive commit message.
3. Add or update tests for behavior changes.
4. Run `python -m pytest` locally.
5. Update documentation when setup, behavior, or limitations change.
6. Open a pull request with a concise summary and test results.

Avoid unrelated formatting changes. Do not include real secrets, personal data, or a populated local database in a contribution.
